# Simulador de Captura Documental

Proyecto desarrollado en Python para practicar la captura de documentos contables.

## Objetivo

Mejorar la velocidad y precisión en la captura de:

- Transferencias bancarias
- Tickets de tiendas
- Recibos
- Facturas
- Estados de cuenta
- Comprobantes

## Tecnologías

- Python
- CustomTkinter
- SQLite
- Pillow
- OpenPyXL
